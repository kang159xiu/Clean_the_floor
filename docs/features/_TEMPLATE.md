# 功能名称

## 目标与边界

说明玩家目标、包含内容、明确不包含内容，以及当前状态。

## 玩家流程

按玩家实际操作顺序描述入口、反馈、成功和失败结果。

## 服务端权威

列出唯一裁决模块、服务端验证、幂等和并发边界。

## 客户端表现

列出本地视觉、输入、Streaming处理和个人隔离规则。

## 数据流

描述Studio/输入 -> Remote -> 服务 -> 状态 -> 快照/事件 -> 客户端的路径。

## 配置

只列配置模块和关键接口，不复制完整数值表。

## Remote

列出方向、参数语义和失败行为；没有则写“无专用Remote”。

## 快照字段

列出本功能拥有的`StateSnapshot`顶层字段。

## 永久字段与重置

列出DataStore顶层字段，以及死亡、离服、Rebirth、完整清档边界。

## Studio契约

列出入口路径和`docs/05_STUDIO_OBJECT_CONTRACT.md`对应章节；未连接目标Place时标记待核验。

## 依赖功能

列出前置功能和被影响功能。

## 不变量

列出任何改动都必须保持的权威、安全、隔离和时序规则。

## 修改影响

列出常见改动需要联动检查的模块、文档和玩家流程。

## 最小回归清单

- [ ] 局部成功路径。
- [ ] 失败或缺失对象路径。
- [ ] 重进、重生或Streaming路径。
