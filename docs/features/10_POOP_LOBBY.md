# 大便、Tool05与大厅牛

## 目标与边界

负责Tool05制造五级便便失物、庭院共享投影、拾取原子事务、大厅牛巡逻与周期生成，以及彩虹便便成功入库后的重生计数。普通失物揭晓与库存由失物功能完成。

## 玩家流程

玩家装备Tool05并触发制造，服务端校验角色、落地、权限、冷却、金币和庭院上限后生成共享便便；任一庭院中的合法玩家拾取后，所有投影同步移除并加入拾取者库存。大厅牛沿路径巡逻并在大厅生成共享便便。

## 服务端权威

`PoopService`只抽取一次等级并用唯一SpawnId维护全服共享条目，负责扣费、投影、领取锁和失败回滚。`LobbyCowService`只提供合法大厅生成请求，不直接授予物品或金币。

## 客户端表现

`PoopController`显示当前庭院和大厅投影、Prompt、拾取反馈与声音。不同庭院看到同一共享条目的不同投影，但任何客户端都不能选择等级或只删除自己的副本。

## 数据流

Tool05输入 -> `RequestMakeTrash` -> 服务端角色/权限/余额/容量校验 -> 共享条目和各庭院投影 -> 快照；拾取请求 -> SpawnId原子锁 -> 全部投影删除 -> LostItem库存提交 -> 快照和声音反馈。

## 配置

Tool05价格、冷却、动作延迟和行为来自`ToolConfig`；五级便便模板、价值和稀有度复用`LostItemConfig`。大厅牛路径与Direction来自Studio对象。

## Remote

`RequestMakeTrash`请求制造，`RequestPoopPickup`请求领取，`PoopSoundTriggered`由服务端向附近客户端发送声音反馈。客户端提交的位置和模板ID都必须重新验证。

## 快照字段

`ActiveYardPoops`、`ActiveLobbyPoops`。彩虹便便计数归区域与重生功能。

## 永久字段与重置

无独占主存档顶层字段。共享便便是会话状态，离服、庭院关闭、Rebirth或完整清档时解除相关投影；成功入库后的图鉴和彩虹计数由所属功能保存。

## Studio契约

便便模板见`ReplicatedStorage资源/失物模板`，声音见`SoundService契约`。大厅牛入口为`Workspace["大厅装扮"].Cow`及其Direction和编号路径点，目标Place现场结构待Studio复核。

## 依赖功能

依赖`yards-visiting`、`lost-items`和`economy-commerce`；教程和重生资格消费制造或拾取结果。

## 不变量

- 同一SpawnId只抽一次等级、只扣一次费用、最多成功领取一次。
- 创建任一投影或扣款失败必须回滚整次事务。
- 访客制造必须同时满足主人权限和服务端庭院上下文。
- 大厅牛结构无效只能关闭牛功能，不能阻断服务器Bootstrap。

## 修改影响

改变上限、投影或拾取时检查所有庭院同步、离服清理、失物库存、Quick Sell、彩虹计数和排行榜。修改Tool05动作需同时检查Automatic与工具状态。

## 最小回归清单

- [ ] 手动/Automatic制造的成功、余额不足、无权限和满20路径正确。
- [ ] 两个庭院同一SpawnId只被领取一次，失败提交按规则恢复。
- [ ] 大厅牛巡逻、地面生成、距离声音和结构无效降级正确。
