# 大便、Tool05与大厅牛

## 目标与边界

负责Tool05制造五级便便失物、个人庭院或Coop共享投影、拾取原子事务、大厅牛巡逻与周期生成，以及彩虹便便成功入库后的重生计数。普通失物揭晓与库存由失物功能完成。

## 玩家流程

玩家装备Tool05并触发制造，服务端校验角色、落地、冷却、固定50金币费用和庭院上限后，只在自己的普通庭院生成便便；好友不能看到或拾取。普通模式成功拾取便便后的前两次有效引导会指向最近兑换处，之后不再重复；兑换时自己制造按基础10、他人制造按等级基础值，再统一乘拾取玩家最新叶价倍率并参与Double Coins。大厅牛沿路径巡逻并在大厅生成全服共享便便；Coop使用全队共享便便池且不运行该教程引导。

## 服务端权威

`PoopService`只抽取一次等级并用唯一SpawnId维护条目，负责扣费、个人/Coop投影、领取锁和失败回滚。普通模式每件只投影到制造者自己的庭院；`LobbyCowService`只提供合法大厅生成请求，不直接授予物品或金币。

## 客户端表现

`PoopController`显示当前个人庭院和大厅投影、Prompt、拾取反馈与声音。普通庭院互相隔离；Coop成员看到同一共享条目。任何客户端都不能选择等级或直接授予库存。

## 数据流

Tool05输入 -> `RequestMakeTrash` -> 服务端角色/余额/容量校验 -> 个人庭院或Coop共享条目 -> 快照；拾取请求 -> SpawnId原子锁 -> 对应投影删除 -> LostItem库存提交 -> 成功回调按教程额度决定兑换引导 -> 快照和声音反馈。

## 配置

Tool05价格、冷却、动作延迟和行为来自`ToolConfig`；五级便便模板、价值和稀有度复用`LostItemConfig`。大厅牛路径与Direction来自Studio对象。

## Remote

`RequestMakeTrash`请求制造，`RequestPoopPickup`请求领取，`PoopSoundTriggered`由服务端向附近客户端发送声音反馈。客户端提交的位置和模板ID都必须重新验证。

## 快照字段

`ActiveYardPoops`、`ActiveLobbyPoops`。彩虹便便计数归区域与重生功能。

## 永久字段与重置

无独占主存档顶层字段。共享便便是会话状态，离服、庭院关闭、Rebirth或完整清档时解除相关投影；成功入库后的图鉴和彩虹计数由所属功能保存。

## Studio契约

便便模板见`ReplicatedStorage资源/失物模板`，声音见`SoundService契约`。大厅牛入口为`Workspace["大厅装扮"].Cow`及其Direction和编号路径点，目标Place现场结构待Studio复核。

## 依赖功能

依赖`yards-visiting`、`lost-items`和`economy-commerce`；教程和重生资格消费制造或拾取结果。

## 不变量

- 同一SpawnId只抽一次等级、只扣一次费用、最多成功领取一次。
- 创建投影或扣款失败必须回滚整次事务。
- 普通模式制造目标只能是制造者本人庭院，其他玩家加入同服不能产生跨庭院投影。
- 大厅牛结构无效只能关闭牛功能，不能阻断服务器Bootstrap。
- 只有便便成功进入失物库存后才能消耗一次兑换引导；失败、重复领取和同一活动引导期间的额外拾取都不能增加次数。

## 修改影响

改变上限、投影或拾取时检查所有庭院同步、离服清理、失物库存、Quick Sell、彩虹计数和排行榜。修改Tool05动作需同时检查Automatic与工具状态。

## 最小回归清单

- [ ] 手动/Automatic制造的成功、余额不足和满20路径正确，固定只扣50金币。
- [ ] 两名普通玩家只看到自己的庭院便便；单个SpawnId最多领取一次，失败提交按规则恢复。
- [ ] 大厅牛巡逻、地面生成、距离声音和结构无效降级正确。
- [ ] 个人庭院与Lobby便便共用账号前两次兑换引导额度；Coop成功拾取不写该额度。

## 合作副本边界

合作局不启动Lobby Cow，大便使用全队共享投影池；任意成员看到同一条目，同一SpawnId仍只能结算一次。制造费用、倍率、兑换和制造榜保持；等待和完成状态拒绝新制造。
