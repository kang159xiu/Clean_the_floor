# 教程、引导线与可购买提醒

## 目标与边界

负责首次教程状态、正式入门漏斗、回收/失物/区域门引导优先级、袋满提示和达到购买条件后的提醒。它不直接执行购买、收取、解锁或兑换。

## 玩家流程

新玩家第1步先跟随引导线前往Area_01最近的正式钱币并显示`Go to the coins`；进入水平距离6 studs后才显示`Hold to Clean 0/15`和`Press to Pick Up`，随后按服务端步骤完成拾取、回收、升级背包和捡手机。基础教程完成后可出现便便、扫把等补充引导：第一次便便引导保留制造、拾取、兑换完整流程，第一轮结束后的下一次有效便便拾取直接引导兑换；账号总共只显示两次兑换引导。常规游玩中，门、回收和普通失物引导根据权威状态选择合法目标。

## 服务端权威

`TutorialService`根据真实收取、回收、升级和拾取回调推进状态，并维护漏斗顺序。便便只有在`LostItemService`成功提交库存后的拾取回调中才可占用一次兑换引导；已有Sell目标时的额外拾取不替换目标或增加次数。客户端按钮点击或动画完成不能直接标记教程完成。

## 客户端表现

`TutorialController`显示当前步骤，并以高优先级来源登记教程常驻文字；第1步通过`YardLeafController`取得Area_01最近有效钱币位置，以本地无碰撞锚点连接现有Beam，目标消失或Streaming未就绪时隐藏并等待。首次靠近或已经成功拾取后，本会话单向切换到拾取提示；管理员完整清档并把角色送回出生点后，通过现有会话重置成功事件清除旧角色留下的靠近状态，重新显示`Go to the coins`。制造便便补充引导会明显放大脉冲Tool05快捷栏按钮。`LostItemGuidanceController`仅在权威`PoopGuidanceStage="Sell"`时为`PoopOnly`物品显示兑换Beam，次数耗尽后不会回退到通用携带物规则；普通失物仍按来源、区域和数量选择商店。

## 数据流

服务端业务成功回调 -> TutorialService更新状态/漏斗 -> 快照`TutorialState` -> 教程文字和引导目标刷新；购买能力由快照金额、等级和配置在客户端只做提示计算。

## 配置

教程步骤、完成状态、节点规则和便便兑换引导上限2来自`TutorialConfig`。购买提醒读取工具、背包、属性和区域Config，不自行保存重复价格表。

## Remote

无专用Remote。教程复用各业务功能的权威成功事件和`StateSnapshot`；引导线不发送解锁、回收或购买结果。

## 快照字段

`TutorialState`。购买提醒和引导还只读Coins、Bag、Tool、Area与库存字段，这些字段仍归各自功能。

## 永久字段与重置

`TutorialCompleted`、`TutorialProgress`、`OnboardingFunnel`；后者持久保存`PoopRedeemGuidanceShownCount`并钳制为0～2。成功拾取并开启引导时立即计数，未兑换便离服也不补回或恢复旧SpawnId；普通死亡在同一会话恢复当前目标。Rebirth关闭当前阶段但保留已用次数，剩余额度可由后续普通模式拾取触发；完整清档归零。旧档缺少计数字段且`PoopGuidanceCompleted=true`时迁移为2，未完成旧档按0继续首次流程。

## Studio契约

见`袋满回收引导`、`教程引导`、`丢失物兑换引导`和`StarterGui契约`。Beam、Attachment或目标缺失时必须隐藏并等待Streaming，不得阻断其他控制器。

## 依赖功能

依赖区域、叶子、工具、背包、失物、经济和HUD功能；它们的权威结果变化都会影响步骤或提示。

## 不变量

- 教程只由成功业务事件推进，失败和重复请求不推进。
- 区域门余额不足或重复碰撞不会推进教程；金币门价只影响门业务，不改变既有引导优先级。
- Lobby共享钱币和`ResetCoin`会话钱币的拾取、即时回收成功事件必须被教程与正式入门漏斗忽略。
- 第1步靠近检测只改变客户端提示，不推进服务端教程；只有Area_01正式钱币的成功收取可推进计数。
- 管理员完整清档必须清除客户端旧角色的第1步靠近状态；普通死亡、Roblox Reset与Rebirth不得重新打开该子阶段。
- 区域门引导优先于普通回收/失物目标，现有教程优先级不得被局部功能覆盖。
- 门金币不足后的Reset Beam沿用区域门引导优先级，同一时刻不得与门、教程、回收或失物Beam并存；到达Reset Prompt后必须释放优先级。
- 教程常驻文字优先于门价建议；教程切换或结束只能清除教程来源，不能误删其他来源。
- 引导目标必须来自大厅或玩家当前可访问区域。
- 引导表现失败不能影响真实玩法入口。
- 便便兑换引导最多显示两次；同一Sell阶段连续拾取不能重复计数，第三次及以后`PoopOnly`物品不能被普通失物规则再次引导。
- 个人庭院与Lobby便便共用该持久额度；Coop不初始化教程服务或客户端失物引导，不消费主档次数。

## 修改影响

修改核心循环中的任何成功事件都需检查教程回调和正式漏斗。新增购买台、回收点或商店需更新目标发现和Streaming回归，但不复制结算逻辑。

## 最小回归清单

- [ ] 新档严格按真实动作推进，失败/重复动作不跳步。
- [ ] 新档先显示前往钱币，进入6 studs后才显示拾取提示；钱币消失、复活和Streaming恢复后目标正确重算。
- [ ] 玩家站在钱币旁执行管理员完整清档并返回出生点后，重新显示`Go to the coins`并指向Area_01；制造便便阶段的Tool05快捷栏脉冲在放大模板上仍清晰可见。
- [ ] 门、回收、失物和袋满状态切换时只显示正确优先目标。
- [ ] 门价建议存在时教程和临时提示可覆盖，教程/临时提示结束后建议恢复且内容不丢失。
- [ ] 重进恢复断点，Rebirth不重开首次教程，缺失目标安全隐藏。
- [ ] 首次完整便便流程占用第1次，结束后下一次有效拾取占用第2次；同一Sell阶段额外拾取不计，第三次及以后无便便兑换Beam。
- [ ] 未兑换离服不补回已用次数，普通死亡恢复当前目标，Rebirth保留计数且完整清档归零；旧完成档迁移为2。

## 合作副本边界

合作局不初始化服务端教程或客户端教程/门外引导控制器，也不写教程进度；主档教程状态由合作保存基线原样保留。
