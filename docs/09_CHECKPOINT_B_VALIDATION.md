## 数据计算规则

- “有效测试者”排除无法进入服务器、客户端崩溃或由组织者中止的技术失败；主动离开、不理解玩法或觉得无聊不得排除。
- “完成玩家”指在同一会话内完成Area_08的玩家。
- 时间使用服务端会话开始到事件的elapsed seconds，不用人工观感估算替代。
- 中位数对排序后的有效值计算；偶数样本取中间两项平均。
- 工具时间占比只用服务端记录的有效工具作用时间，不把单纯装备待机算入。

## 调整与重测

1. 首次回收或早期购买失败：先调回收收益、初期袋子价格和升级价格。
2. 工具购买时间或使用率失败：再调工具价格、效率和差异。
3. 单区时间失败：再调该区叶子量或叶子价值。
4. 只有前三层无法达到总时长时，才调整八区总结构。

任何参数调整都创建新配置版本，并重跑3次内部完整路线。涉及失物概率时同时重跑每区100,000次自动抽样。
